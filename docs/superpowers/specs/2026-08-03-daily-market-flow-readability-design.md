# 日报大盘资金可读性修复设计

## 目标

把日报“市场温度”区的大盘资金展示从原始元数改为固定亿元口径，便于阅读；不改变资金快照中的原始数值、市场温度判定、数据采集或其他报告段落。

## 展示契约

输入为 `market_flow.main_net_inflow` 和 `market_flow.super_large_net_inflow`（单位：元）。有效有限数值统一转换为亿元，保留一位小数和显式正负号：

```text
大盘资金：主力净流入 +625.4亿元；超大单净流入 +699.9亿元
```

负值示例：

```text
大盘资金：主力净流入 -125.0亿元；超大单净流入 -80.5亿元
```

零值显示 `+0.0亿元`，保持方向字段的统一格式。缺失、无效或非有限数值沿用现有 `_as_float()` 的兼容行为；本修复不新增采集失败或温度降级逻辑。

## 范围与兼容性

- 仅修改 `application/professional_flow_daily.py` 中 `_market_notes()` 生成的大盘资金备注；
- 不修改 `flow_snapshots` JSON schema 或保存值；
- 不修改行业、个股资金流及月报/周报的格式化函数；
- 不影响 ETF、两融、数据质量或通知推送逻辑。

## 测试

- 以 2026-07-31 的真实量级回归：`62_535_737_344` 和 `69_993_807_872` 渲染为 `+625.4亿元` 和 `+699.9亿元`；
- 负数与零值的正负号、单位和一位小数；
- 断言报告不再出现未格式化的原始元数；
- 原有市场温度与两融/ETF 文案测试保持通过。
