# 日报弹簧三态扫描设计

## 背景

当前职业资金雷达日报包含“弹簧买点观察”，但其筛选依据是 20/60/120 日收益率组合形成的 `setup_score`。该分数只能代理描述“上涨后回撤、短期企稳”，没有读取 MA20、成交量、K 线或回踩次数，因此不能严格区分弹簧理论中的压紧、首阳和弱弹簧。

日报行情采集阶段已经取得个股日线 OHLCV，并在配置数据库时写入 `price_daily`。本次改造复用采集阶段内存中的日线数据，通过纯规则生成可复现的三态结果，不增加一次行情请求，也不引入大模型判断。

## 目标

- 以 MA20 为主支撑，在日报中识别“压紧观察 / 首阳确认 / 弱弹簧排除”三种外显状态。
- 在日报中固定解释三态含义，避免把形态状态误读为买卖建议。
- 展示弱弹簧及其排除原因，使筛选过程可以核验。
- 复用现有行情采集结果，不重复联网取数。
- 对旧快照、单股失败和数据不足保持兼容并明确降级。

## 非目标

- 不使用 AI 或自然语言模型判定弹簧状态。
- 不把“首阳确认”直接升级为 `2%候选`，也不生成具体买卖建议。
- 不以 MA5、MA10 或 MA60 独立触发三态；它们可在未来作为辅助证据扩展。
- 不在本次改造中扩展周报、月报或持仓专项扫描。
- 不改变市场温度、板块、资金流、`2%候选` 的既有判定契约。

## 设计选择

### 采用：行情采集时计算精简结果

`collect_price_snapshot_batch()` 已经逐只取得完整日线 DataFrame。新增纯规则分析函数，在 DataFrame 仍位于内存时计算弹簧事实和状态，并把精简结果附加到对应价格快照行。

优点：

- 不重复请求行情。
- 报告生成不强依赖 SQLite，未配置数据库的运行方式仍可使用。
- 快照保存了当时使用的规则结果，日报可以复现。
- 不需要把最近 60 根完整 K 线写入价格快照，控制文件体积。

未采用的方案：

- 报告阶段查询 `price_daily`：会让日报新增数据库完整性依赖，无数据库运行和旧部署更容易退化。
- 继续使用收益率代理并只改标签：无法识别真实支撑、缩量和首阳，不满足本次目标。

## 数据契约

### 输入

每只 A 股至少需要 79 条日线输入，且最新 79 条必须全部有效。原因是回踩统计覆盖最近 60 个交易日，而统计窗口最早一天仍需要此前 19 日计算当日 MA20。

输入先解析全部 `trade_date` 以便排序；存在无法解析的日期时整只股票返回 `unknown`。日期有效后按升序排列并截取最新 79 根，同一交易日在这 79 根中重复属于无效输入，不允许静默选择其中一条。所需字段为：

- `trade_date`
- `open`
- `high`
- `low`
- `close`
- `volume`

价格和成交量必须为有限正数。计算均线和支撑距离使用采集源已经完成前复权的 `close`；不混用未复权价格。零成交量不得解释成缩量，避免停牌或源数据缺失产生假信号。

除为排序而解析全部日期外，价格和成交量校验只检查最新 79 根输入，不因更早的历史坏值关闭当前判断。最新 79 根中任意一根所需字段无效时，整只股票返回 `unknown`；不得丢弃坏值后用更早数据补足 79 根，也不得前向填充价格或成交量。少于 79 根时使用 `insufficient_history`，重复交易日使用 `duplicate_trade_date`，其余价格、日期或成交量问题分别使用对应的无效数据原因码。

### 快照扩展

现有价格快照行保留全部旧字段，新增可选的 `spring` 对象：

```json
{
  "spring": {
    "rule_version": "ma20-v1",
    "state": "compressed_watch",
    "as_of": "2026-08-04",
    "ma20_distance_pct": 0.008,
    "volume_compression_ratio": 0.28,
    "support_touch_count_60d": 1,
    "reasons": []
  }
}
```

内部状态固定为：

| 内部状态 | 含义 | 是否进入三态栏目 |
| --- | --- | --- |
| `compressed_watch` | 压紧但未出现首阳 | 是 |
| `first_bullish_confirmed` | 压紧后当日出现第一根阳线 | 是 |
| `weak_excluded` | 弱弹簧，已排除 | 是 |
| `none` | 当前没有弹簧形态 | 否 |
| `unknown` | 数据不足或无法安全计算 | 否，计入数据质量 |

新生成的快照必须为每只成功取得价格快照的 A 股写入 `spring` 对象，包括 `none` 和 `unknown`。只有历史快照允许完全缺少该对象。`rule_version` 用于区分未来规则变化；`as_of` 必须取该股票日线的最新交易日，不能直接复制报告日。

`reasons` 使用稳定原因码，不直接保存中文文案：

- `ma20_broken`
- `third_support_test`
- `volume_not_compressed`
- `insufficient_history`
- `duplicate_trade_date`
- `invalid_trade_date`
- `invalid_price_data`
- `invalid_volume_data`
- `zero_volume_baseline`

展示层负责把原因码映射成中文。未知原因码必须保守显示为“规则原因暂不可用”，不能泄漏内部英文值。

## 规则定义

### 基础指标

1. `MA20` 为最近 20 个交易日收盘价简单平均值。
2. MA20 向上定义为：今日 MA20 严格高于 5 个交易日前的 MA20。
3. MA20 距离定义为：`今日收盘价 / 今日 MA20 - 1`。
4. 当日支撑触及需要同时满足：
   - 当日最低价不高于 `MA20 × 1.02`；
   - 当日收盘价不低于 `MA20 × 0.98`。
5. 有效跌破只看最新 2 个交易日：这两日收盘价均低于各自 MA20 的 2% 时成立。更早出现过连续跌破、但最新两日已经修复的，不得继续触发该状态。

MA20 上下 2% 的边界为闭区间；恰好 `+2%` 或 `-2%` 均按触及处理，不按跌破处理。

支撑触及允许“下探后收回”的长下影：即使最低价一度低于 `MA20 × 0.98`，只要收盘重新站到该下限之上仍算触及。但“压紧观察”还要求当日收盘不高于 `MA20 × 1.02`；收盘已经弹离支撑带上沿、又不满足首阳的股票返回 `none`，不能继续标为压紧。

### 独立回踩次数

- 统计窗口为最近 60 个交易日。
- 先按每日 MA20 判断支撑触及。
- 先把连续触及日组成原始回踩段；每个原始段的锚点取该段最后一个触及日。
- 按时间依次比较相邻原始段。若两个锚点在 60 日窗口中的位置分别为 `i` 和 `j`，使用位置差 `j - i`：小于 5 时合并为同一回踩段，合并后锚点更新为后一个原始段的最后触及日，再继续比较下一段。
- `j - i == 5` 时不合并，计为两次独立回踩。这里的“间隔 5 个交易日”指锚点位置差为 5，不是中间必须存在 5 个完整交易日。
- 合并后的回踩段从第一个原始段首日延伸到最后一个原始段末日，中间未触及的交易日也属于该段的上下文。连续贴线或短间隔反复贴线只能计数一次。
- 当日位于最近 60 日的第 3 个或后续独立回踩段时，优先判为弱弹簧。

这对应“第一次正常、第二次减弱、第三次回避”的保守执行口径。三态第一版不单独展示“第二次减半”的仓位建议，只展示回踩次数这一事实。

### 缩量比

先在不考虑成交量的情况下判断当日是否满足首阳 K 线条件，再确定压紧窗口的截止日：

- 当日是首阳候选时，压紧窗口截止到前一交易日，使用首阳之前 3 个交易日的平均成交量。
- 当日不是首阳候选时，压紧窗口截止到当日，使用最近 3 个交易日的平均成交量。

前期活跃量能：排除上述 3 日压紧窗口后，向前 40 个交易日内所有连续 5 日平均成交量的最大值。

缩量比定义为：

```text
压紧窗口 3 日平均成交量 / 此前 40 日最高 5 日平均成交量
```

- 缩量比小于或等于 30% 时，缩量成立。
- 缩量比恰好为 30% 时按成立处理。
- 首阳当日成交量不进入压紧缩量比。首阳可以温和放量；只要首阳前 3 日已经压紧，首阳当日放量本身不能把状态降级为“缩量不足”。
- 输入成交量存在 NaN、零、负数，或前期活跃量能为零时，状态为 `unknown`，不得用零值替代。

### 第一根阳线

首阳候选日必须同时满足：

- 当日属于最新回踩段；
- 当日 `close > open`；
- 当日 `close > 前一交易日 close`；
- 合并后的最新回踩段从段首到昨日之间，没有交易日满足以上两条阳线条件。

因此“首阳确认”是一个当日事件，不会因为随后继续收阳而连续多日重复标记。如果最新回踩段已经出现过首阳，后续交易日重新按规则判断为 `none`，直到形成新的独立回踩段。

### 状态优先级

状态判断前先执行输入校验。有效日线不足 79 条、价格或成交量无效、成交量基准为零时直接返回 `unknown`，不得继续套用弱弹簧或首阳规则。

输入有效后先计算全部适用的弱弹簧原因，再按以下顺序选出唯一状态：

| 优先级 | 条件 | 内部状态 | 日报状态 |
| ---: | --- | --- | --- |
| 1 | 满足任一弱弹簧原因：当日位于第 3 次或后续回踩段；最近 10 日有回踩且最新 2 日有效跌破；MA20 向上且当日触及但对应压紧窗口缩量比大于 30% | `weak_excluded` | 弱弹簧排除 |
| 2 | MA20 向上、当日触及支撑、缩量成立，且出现首阳 | `first_bullish_confirmed` | 首阳确认 |
| 3 | MA20 向上、当日收盘仍在 MA20 上下 2% 内、触及支撑、缩量成立，尚未出现首阳 | `compressed_watch` | 压紧观察 |
| 4 | 其余 | `none` | 不展示 |

“最近形成回踩上下文”定义为最近 10 个交易日内至少出现过一次支撑触及，用于避免把长期远离 MA20 后的普通下跌误标为弱弹簧。

任一弱弹簧原因都优先于首阳。即使第 3 次回踩当日收阳，也进入“弱弹簧排除”；满足多个弱弹簧条件时保存全部原因。

缩量不足同样优先于首阳，但“首阳日”的缩量依据是首阳之前 3 日，而不是包含首阳当日的 3 日平均量。也就是说，首阳前没有压紧会被排除，首阳当日温和放量不会被排除。

## 扫描范围与旧评分关系

- 扫描范围只包括当次价格快照中 `market == "cn"` 且具备日线输入的 A 股，不要求该股票必须出现在当日个股资金流排名中。
- 个股资金流缺失不影响纯技术三态计算；资金流数据仍可用于现有综合分和并列排序。
- 旧 `setup_score` 可继续参与既有综合评分，但不得生成或覆盖 `spring.state`。
- 旧 `setup_watch` 列表及其 `setup_score >= 60`、无背离、非防守过滤整体停止用于报告渲染，由三个 `spring.state` 列表替代。不得同时保留旧“弹簧买点观察”列表。
- 旧快照中的 `market == "cn"` 行没有 `spring` 字段时，展示层按 `unknown` 降级，不允许回退到收益率代理并冒充三态结果。
- US、HK 及其他非 `cn` 行没有 `spring` 字段属于正常范围外数据，不生成 `unknown`，不计入弹簧三态数据质量。
- 一句话结论不再使用“建议观望或布局弹簧买点”，改为中性提示“弹簧三态扫描见下文”，避免旧代理口径和操作性措辞残留。

## 日报展示

### 栏目结构

原“弹簧买点观察”改为“弹簧三态扫描”，固定包含说明和三个小节：

```text
## 弹簧三态扫描

三态说明：压紧观察表示上升的 MA20 附近已缩量，但尚未出现首阳；
首阳确认表示压紧后出现第一根阳线，仅代表形态确认；
弱弹簧排除表示反复回踩、跌破支撑或缩量不足，暂不列入候选。

### 首阳确认

### 压紧观察

### 弱弹簧排除
```

说明中必须保留“仅代表形态确认”，不能把首阳描述为买入信号或买入建议。

### 单股文案

首阳确认和压紧观察显示：

```text
特锐德 (300001.SZ)：首阳确认｜距 MA20 +0.8%｜缩量比 28%｜近60日第1次回踩
```

弱弹簧必须显示排除原因：

```text
某股票 (000001.SZ)：弱弹簧排除｜近60日第3次回踩
某股票 (000002.SZ)：弱弹簧排除｜连续2日有效跌破 MA20
某股票 (000003.SZ)：弱弹簧排除｜回踩时缩量不足（缩量比 46%）
```

每个空小节显示“暂无”，不能省略整个小节，也不能用空白暗示采集成功。

### 数量与排序

- 首阳确认最多 5 只。
- 压紧观察最多 10 只。
- 弱弹簧排除最多 5 只。

首阳确认和压紧观察分别按以下键稳定排序：

1. 独立回踩次数升序；
2. MA20 绝对距离升序；
3. 缩量比升序；
4. 有现有综合分的排在无综合分的前面，有综合分时按分数降序；缺失值不得当作 0 分；
5. 股票代码升序。

弱弹簧可以同时满足多个原因。`reasons` 按“有效跌破 MA20、第 3 次回踩、缩量不足”的稳定顺序保存并全部展示，排序时取其中最高优先级原因作为主原因：

- 有效跌破 MA20：最新两日中更低的 MA20 距离升序（跌得更深在前），再按回踩次数降序、股票代码升序。
- 第 3 次回踩：回踩次数降序、MA20 绝对距离升序、股票代码升序。
- 缩量不足：缩量比降序、MA20 绝对距离升序、股票代码升序。

市场温度为“防守”时仍展示扫描事实，但在三态说明后增加：

```text
防守模式：三态结果仅供形态跟踪，不进入候选。
```

## 降级与错误处理

- 单只股票计算失败不能中断其他股票或整份日报。
- 只有 `market == "cn"` 的 `unknown` 股票进入弹簧数据质量统计；非 A 股行不进入三个状态列表，也不产生该类警告。
- 数据质量段按原因汇总数量，例如：

```text
⚠️ 弹簧三态：12 只有效日线不足，3 只成交量数据无效；这些股票本次暂不判断。
```

重复交易日按 `duplicate_trade_date` 单独汇总为“交易日重复”，不混入普通价格无效；其他内部原因码均通过固定中文词表汇总，不直接输出英文。

- 如果所有 A 股都无法计算，三态三个小节仍显示“暂无”，数据质量明确显示：

```text
⚠️ 弹簧三态暂不判断：没有股票具备计算最近60日回踩所需的79条有效日线。
```

- `none` 是正常无形态，不产生数据质量警告。
- 写入快照时的三态失败只影响对应股票新增字段，不得丢弃该股票原有收益率快照。

## 验收标准

### 规则真值表

- [ ] MA20 向上、当日回踩、缩量比不高于 30%、尚无首阳，得到“压紧观察”。
- [ ] 上述条件满足且当日出现回踩段第一根阳线，得到“首阳确认”。
- [ ] 当日位于最近 60 日第 3 个独立回踩段，得到“弱弹簧排除”，且优先于首阳。
- [ ] 最近 10 日存在回踩上下文且最新 2 日收盘均低于各自 MA20 的 2%，得到“弱弹簧排除”；更早跌破但最新两日已修复时不触发。
- [ ] MA20 向上且当日回踩，但缩量比大于 30%，得到“弱弹簧排除”。
- [ ] 首阳前 3 日已经缩量时，首阳当日温和放量仍得到“首阳确认”；首阳前 3 日未缩量时得到“弱弹簧排除”。
- [ ] 普通上涨且远离 MA20，不进入三态。
- [ ] MA20 下行时，即使靠近 MA20，也不得进入压紧观察或首阳确认。
- [ ] 长下影触及 MA20 且收回下限可以形成回踩；非首阳且收盘高于 MA20 上沿 2% 时不得标成“压紧观察”。
- [ ] 日线输入少于 79 条，或最新 79 条并非全部有效时得到 `unknown`，不得伪装为候选。

### 边界条件

- [ ] 收盘价距离 MA20 恰好 `+2%` 或 `-2%` 时按支撑范围处理。
- [ ] 缩量比恰好为 30% 时按缩量成立处理。
- [ ] 两个回踩段锚点位置差 `j - i == 5` 时，计为两次独立回踩。
- [ ] 两个原始回踩段锚点间隔少于 5 个交易日时合并，更新锚点后再与下一段比较；首阳“此前”范围从合并段首开始。
- [ ] 连续贴近 MA20 多日只计一次回踩。
- [ ] 第 3 次回踩当日即使满足首阳，也只进入弱弹簧排除；离开该回踩段后不因历史上出现过第 3 次回踩而持续重复展示。
- [ ] 首阳后的第二根连续阳线不再重复标为首阳确认。
- [ ] 最新 79 根中成交量存在 NaN、零、负数或前期基准为零时关闭判断并给出具体原因。
