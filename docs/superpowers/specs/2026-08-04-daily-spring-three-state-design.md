# 日报弹簧三态扫描设计

## 背景

当前职业资金雷达日报包含“弹簧买点观察”，但其筛选依据是 20/60/120 日收益率组合形成的 `setup_score`。该分数只能代理描述“上涨后回撤、短期企稳”，没有读取 MA20、成交量、K 线或回踩次数，因此不能严格区分弹簧理论中的压紧、首阳和弱弹簧。

日报行情采集阶段已经取得个股日线 OHLCV，并在配置数据库时写入 `price_daily`。本次改造复用采集阶段内存中的日线数据，通过纯规则生成可复现的三态结果，不增加一次行情请求，也不引入大模型判断。

## 目标

- 以 MA20 为主支撑，在日报中识别“压紧观察 / 首阳确认 / 弱弹簧排除”三种外显状态。
- 在日报中固定解释三态含义，避免把形态状态误读为买卖建议。
- 展示弱弹簧及其排除原因，使筛选过程可以核验。
- 复用现有行情采集结果，不重复联网取数。
- 对旧快照、单股失败和数据不足保持兼容并明确降级。

## 非目标

- 不使用 AI 或自然语言模型判定弹簧状态。
- 不把“首阳确认”直接升级为 `2%候选`，也不生成具体买卖建议。
- 不以 MA5、MA10 或 MA60 独立触发三态；它们可在未来作为辅助证据扩展。
- 不在本次改造中扩展周报、月报或持仓专项扫描。
- 不改变市场温度、板块、资金流、`2%候选` 的既有判定契约。

## 设计选择

### 采用：行情采集时计算精简结果

`collect_price_snapshot_batch()` 已经逐只取得完整日线 DataFrame。新增纯规则分析函数，在 DataFrame 仍位于内存时计算弹簧事实和状态，并把精简结果附加到对应价格快照行。

优点：

- 不重复请求行情。
- 报告生成不强依赖 SQLite，未配置数据库的运行方式仍可使用。
- 快照保存了当时使用的规则结果，日报可以复现。
- 不需要把最近 60 根完整 K 线写入价格快照，控制文件体积。

未采用的方案：

- 报告阶段查询 `price_daily`：会让日报新增数据库完整性依赖，无数据库运行和旧部署更容易退化。
- 继续使用收益率代理并只改标签：无法识别真实支撑、缩量和首阳，不满足本次目标。

## 数据契约

### 输入

每只 A 股至少需要最近 79 条有效日线。原因是回踩统计覆盖最近 60 个交易日，而统计窗口最早一天仍需要此前 19 日计算当日 MA20。

输入先按 `trade_date` 升序排列；同一交易日重复记录属于无效输入，不允许静默选择其中一条。所需字段为：

- `trade_date`
- `open`
- `high`
- `low`
- `close`
- `volume`

价格和成交量必须为有限正数。计算均线和支撑距离使用采集源已经完成前复权的 `close`；不混用未复权价格。零成交量不得解释成缩量，避免停牌或源数据缺失产生假信号。

### 快照扩展

现有价格快照行保留全部旧字段，新增可选的 `spring` 对象：

```json
{
  "spring": {
    "rule_version": "ma20-v1",
    "state": "compressed_watch",
    "as_of": "2026-08-04",
    "ma20_distance_pct": 0.008,
    "volume_compression_ratio": 0.28,
    "support_touch_count_60d": 1,
    "reasons": []
  }
}
```

内部状态固定为：

| 内部状态 | 含义 | 是否进入三态栏目 |
| --- | --- | --- |
| `compressed_watch` | 压紧但未出现首阳 | 是 |
| `first_bullish_confirmed` | 压紧后当日出现第一根阳线 | 是 |
| `weak_excluded` | 弱弹簧，已排除 | 是 |
| `none` | 当前没有弹簧形态 | 否 |
| `unknown` | 数据不足或无法安全计算 | 否，计入数据质量 |

新生成的快照必须为每只成功取得价格快照的 A 股写入 `spring` 对象，包括 `none` 和 `unknown`。只有历史快照允许完全缺少该对象。`rule_version` 用于区分未来规则变化；`as_of` 必须取该股票日线的最新交易日，不能直接复制报告日。

`reasons` 使用稳定原因码，不直接保存中文文案：

- `third_support_test`
- `ma20_broken`
- `volume_not_compressed`
- `insufficient_history`
- `invalid_price_data`
- `invalid_volume_data`
- `zero_volume_baseline`

展示层负责把原因码映射成中文。未知原因码必须保守显示为“规则原因暂不可用”，不能泄漏内部英文值。

## 规则定义

### 基础指标

1. `MA20` 为最近 20 个交易日收盘价简单平均值。
2. MA20 向上定义为：今日 MA20 严格高于 5 个交易日前的 MA20。
3. MA20 距离定义为：`今日收盘价 / 今日 MA20 - 1`。
4. 当日支撑触及需要同时满足：
   - 当日最低价不高于 `MA20 × 1.02`；
   - 当日收盘价不低于 `MA20 × 0.98`。
5. 有效跌破定义为连续 2 个交易日收盘价均低于各自 MA20 的 2%。

MA20 上下 2% 的边界为闭区间；恰好 `+2%` 或 `-2%` 均按触及处理，不按跌破处理。

### 独立回踩次数

- 统计窗口为最近 60 个交易日。
- 先按每日 MA20 判断支撑触及。
- 连续触及日合并为同一个回踩段，连续贴线多日只能计数一次。
- 两个非连续回踩段的锚点至少间隔 5 个交易日，才计为两次独立回踩。
- 当日位于最近 60 日的第 3 个或后续独立回踩段时，优先判为弱弹簧。

这对应“第一次正常、第二次减弱、第三次回避”的保守执行口径。三态第一版不单独展示“第二次减半”的仓位建议，只展示回踩次数这一事实。

### 缩量比

当前压紧量能：最近 3 个交易日平均成交量。

前期活跃量能：排除最近 3 日后，向前 40 个交易日内所有连续 5 日平均成交量的最大值。

缩量比定义为：

```text
最近 3 日平均成交量 / 前 40 日最高 5 日平均成交量
```

- 缩量比小于或等于 30% 时，缩量成立。
- 缩量比恰好为 30% 时按成立处理。
- 输入成交量存在 NaN、负数，或前期活跃量能为零时，状态为 `unknown`，不得用零值替代。

### 第一根阳线

首阳候选日必须同时满足：

- 当日属于最新回踩段；
- 当日 `close > open`；
- 当日 `close > 前一交易日 close`；
- 最新回踩段此前没有交易日满足以上两条阳线条件。

因此“首阳确认”是一个当日事件，不会因为随后继续收阳而连续多日重复标记。如果最新回踩段已经出现过首阳，后续交易日重新按规则判断为 `none`，直到形成新的独立回踩段。

### 状态优先级

状态判断前先执行输入校验。有效日线不足 79 条、价格或成交量无效、成交量基准为零时直接返回 `unknown`，不得继续套用弱弹簧或首阳规则。

输入有效后按以下顺序短路，避免同一股票同时落入多个状态：

| 优先级 | 条件 | 内部状态 | 日报状态 |
| ---: | --- | --- | --- |
| 1 | 当日位于最近 60 日的第 3 个或后续独立回踩段 | `weak_excluded` | 弱弹簧排除 |
| 2 | 最近形成回踩上下文，且连续 2 日有效跌破 MA20 | `weak_excluded` | 弱弹簧排除 |
| 3 | MA20 向上且当日触及支撑，但缩量比大于 30% | `weak_excluded` | 弱弹簧排除 |
| 4 | MA20 向上、当日触及支撑、缩量成立，且出现首阳 | `first_bullish_confirmed` | 首阳确认 |
| 5 | MA20 向上、当日触及支撑、缩量成立，尚未出现首阳 | `compressed_watch` | 压紧观察 |
| 6 | 其余 | `none` | 不展示 |

“最近形成回踩上下文”定义为最近 10 个交易日内至少出现过一次支撑触及，用于避免把长期远离 MA20 后的普通下跌误标为弱弹簧。

第 3 次回踩优先于首阳：即使第 3 次回踩当日收阳，也进入“弱弹簧排除”。

## 扫描范围与旧评分关系

- 扫描范围为当次价格快照中具备日线输入的 A 股，不要求该股票必须出现在当日个股资金流排名中。
- 个股资金流缺失不影响纯技术三态计算；资金流数据仍可用于现有综合分和并列排序。
- 旧 `setup_score` 可继续参与既有综合评分，但不得生成或覆盖 `spring.state`。
- 旧快照没有 `spring` 字段时，展示层按 `unknown` 降级，不允许回退到收益率代理并冒充三态结果。

## 日报展示

### 栏目结构

原“弹簧买点观察”改为“弹簧三态扫描”，固定包含说明和三个小节：

```text
## 弹簧三态扫描

三态说明：压紧观察表示上升的 MA20 附近已缩量，但尚未出现首阳；
首阳确认表示压紧后出现第一根阳线，仅代表形态确认；
弱弹簧排除表示反复回踩、跌破支撑或缩量不足，暂不列入候选。

### 首阳确认

### 压紧观察

### 弱弹簧排除
```

说明中必须保留“仅代表形态确认”，不能把首阳描述为买入信号或买入建议。

### 单股文案

首阳确认和压紧观察显示：

```text
特锐德 (300001.SZ)：首阳确认｜距 MA20 +0.8%｜缩量比 28%｜近60日第1次回踩
```

弱弹簧必须显示排除原因：

```text
某股票 (000001.SZ)：弱弹簧排除｜近60日第3次回踩
某股票 (000002.SZ)：弱弹簧排除｜连续2日有效跌破 MA20
某股票 (000003.SZ)：弱弹簧排除｜回踩时缩量不足（缩量比 46%）
```

每个空小节显示“暂无”，不能省略整个小节，也不能用空白暗示采集成功。

### 数量与排序

- 首阳确认最多 5 只。
- 压紧观察最多 10 只。
- 弱弹簧排除最多 5 只。

首阳确认和压紧观察分别按以下键稳定排序：

1. 独立回踩次数升序；
2. MA20 绝对距离升序；
3. 缩量比升序；
4. 现有综合分降序；
5. 股票代码升序。

弱弹簧风险原因按“有效跌破 MA20、第 3 次回踩、缩量不足”排序；同一原因内再按风险程度和股票代码稳定排序。

市场温度为“防守”时仍展示扫描事实，但在三态说明后增加：

```text
防守模式：三态结果仅供形态跟踪，不进入候选。
```

## 降级与错误处理

- 单只股票计算失败不能中断其他股票或整份日报。
- `unknown` 股票不进入三个状态列表。
- 数据质量段按原因汇总数量，例如：

```text
⚠️ 弹簧三态：12 只有效日线不足，3 只成交量数据无效；这些股票本次暂不判断。
```

- 如果所有 A 股都无法计算，三态三个小节仍显示“暂无”，数据质量明确显示：

```text
⚠️ 弹簧三态暂不判断：没有股票具备计算最近60日回踩所需的79条有效日线。
```

- `none` 是正常无形态，不产生数据质量警告。
- 写入快照时的三态失败只影响对应股票新增字段，不得丢弃该股票原有收益率快照。

## 验收标准

### 规则真值表

- [ ] MA20 向上、当日回踩、缩量比不高于 30%、尚无首阳，得到“压紧观察”。
- [ ] 上述条件满足且当日出现回踩段第一根阳线，得到“首阳确认”。
- [ ] 当日位于最近 60 日第 3 个独立回踩段，得到“弱弹簧排除”，且优先于首阳。
- [ ] 最近 10 日存在回踩上下文且连续 2 日收盘低于 MA20 的 2%，得到“弱弹簧排除”。
- [ ] MA20 向上且当日回踩，但缩量比大于 30%，得到“弱弹簧排除”。
- [ ] 普通上涨且远离 MA20，不进入三态。
- [ ] MA20 下行时，即使靠近 MA20，也不得进入压紧观察或首阳确认。
- [ ] 有效日线少于 79 条时得到 `unknown`，不得伪装为候选。

### 边界条件

- [ ] 收盘价距离 MA20 恰好 `+2%` 或 `-2%` 时按支撑范围处理。
- [ ] 缩量比恰好为 30% 时按缩量成立处理。
- [ ] 两个回踩段锚点恰好间隔 5 个交易日时，计为两次独立回踩。
- [ ] 连续贴近 MA20 多日只计一次回踩。
- [ ] 第 3 次回踩当日即使满足首阳，也只进入弱弹簧排除；离开该回踩段后不因历史上出现过第 3 次回踩而持续重复展示。
- [ ] 首阳后的第二根连续阳线不再重复标为首阳确认。
- [ ] 成交量存在 NaN、负数或前期基准为零时关闭判断并给出具体原因。
- [ ] 价格存在 NaN、非正数或日期乱序时，安全归一化或关闭对应股票判断。

### 快照兼容

- [ ] 新快照保留现有 `latest_close` 和各窗口收益率字段。
- [ ] 新快照为每只成功取得价格快照的 A 股写入稳定、可 JSON 序列化的 `spring` 对象，并包含 `rule_version` 和真实行情截止日 `as_of`。
- [ ] 单股三态计算失败时，该股票原价格快照仍被保存。
- [ ] 旧快照没有 `spring` 字段时可以继续读取，报告明确降级而不使用旧代理冒充三态。
- [ ] 配置和未配置 SQLite 的日报任务都能生成相同三态结果。

### 报告文案

- [ ] 日报固定解释“压紧观察 / 首阳确认 / 弱弹簧排除”。
- [ ] 解释明确“首阳确认仅代表形态确认”，不构成具体买卖建议。
- [ ] 三类结果分别显示，单只股票不能同时进入两个小节。
- [ ] 弱弹簧逐只显示排除原因，不出现裸内部原因码。
- [ ] 有效结果显示 MA20 距离、缩量比和最近 60 日回踩次数；不适用指标可以省略但不得伪造。
- [ ] 三个空列表均显示“暂无”。
- [ ] 防守模式显示“仅供形态跟踪，不进入候选”。
- [ ] 数据不足时，“数据质量”给出受影响数量和具体原因。

### 回归、部署与当日报告

- [ ] 现有日报市场温度、资金主线、`2%候选`、资金流、证伪提醒和推送逻辑保持不变。
- [ ] 三态规则单元测试、报告渲染测试、价格快照兼容测试通过。
- [ ] 完整测试套件和 Ruff 通过。
- [ ] 代码合并并推送后，VPS 更新到包含本功能的提交。
- [ ] 在 VPS 重跑 2026-08-04 日报；落盘报告和推送正文一致。
- [ ] 重推日报包含三态解释、三个独立小节、可读指标和明确的数据质量信息。
- [ ] 核验重跑没有额外行情请求，也没有因单股三态失败导致整份日报失败。

## 实施边界

方案通过后，实施阶段应先为规则真值表编写失败测试，再实现纯规则分析、快照扩展和报告渲染。实现完成并通过本地验收前，不得直接修改 VPS 或重推日报。
